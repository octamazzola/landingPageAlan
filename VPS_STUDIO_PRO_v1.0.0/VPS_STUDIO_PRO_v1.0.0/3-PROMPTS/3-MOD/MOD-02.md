# MOD-02 · Minimal Context Module

VPS 1.0.0 · EN MASTER · Copy/paste the prompt body below.

```text
Use only when the source background is incomplete, blank, clipped, or neutral. Extend context by the minimum amount required for a coherent image, matching the project’s apparent location, scale, horizon, ground level, perspective, climate, time of day, light direction, atmospheric depth, and material logic. Keep all added context low-detail, low-contrast, visually subordinate, and outside critical architectural silhouettes, entrances, circulation paths, and view corridors. Do not invent landmarks, dramatic landscapes, dense vegetation, neighboring architecture, signage, or activity unless directly supported by the source.
```
