# CAM-05 · Telephoto-style framing

VPS 1.0.0 · EN MASTER · Copy/paste the prompt body below.

```text
PURPOSE  Apply a controlled camera or post-production effect to the uploaded architectural image while treating the source as the immutable record of the visible project. Change only the photographic presentation explicitly requested below.

ANALYSIS + GATE  Before editing, identify the original crop, aspect ratio, viewpoint, camera height, horizon, vanishing points, lens behavior, distortion, depth order, focal plane, exposure, dynamic range, white balance, light sources, motion cues, sharpness, noise and grain. Apply the compatibility gate exactly. If the effect requires pixels, depth information or moving subjects that are not present, do not invent them; keep the source unchanged or apply a weaker valid version. This is a crop-based simulation; it cannot create true lens compression from a new viewpoint.

REQUESTED EDIT  Simulate a refined telephoto-style architectural framing through a centered or strategically offset crop of the existing image. Emphasize visible layered planes and distant details without reprojecting perspective. Preserve all relative positions, convergence, scale and occlusion exactly. Apply only subtle local contrast and atmospheric balancing consistent with a longer-lens editorial look. Do not move planes closer, flatten depth artificially or synthesize unseen side content.

PHYSICAL / OPTICAL INTEGRATION  Use one coherent optical model across the whole image. Keep edges, masks and transitions depth-aware, continuous and free of halos. Preserve physically credible scale, occlusion, perspective, material mapping, reflections, shadow geometry, noise structure and resolution. Any crop must stay inside the original frame. Any correction must be global and projective rather than elastic. Any blur, bloom or sharpening must respond only to existing depth, motion and light evidence.

PRESERVATION LOCK  Preserve every visible architectural element, geometry, proportion, opening, joint, material, texture, furniture, landscape, vegetation, person, vehicle, sign, artwork, sky, light direction and color identity. Do not add, delete, relocate, redesign, extend or reconstruct architecture. Do not generate hidden surfaces, new viewpoints or off-frame context. Retain the source as the single source of truth.

NEGATIVE CONSTRAINTS  No outpainting, generative fill, invented geometry, new object, changed material, altered weather, synthetic lighting source, elastic deformation, broken vertical, warped text, duplicated element, halo, edge contamination, over-sharpening, plastic texture, excessive HDR, crushed black, clipped highlight, inconsistent blur, fake lens artifact or visible AI/compositing trace. Do not claim or simulate a physically new camera position.

FINAL RESULT  Deliver a professional architectural photograph with a clearly intentional camera language and complete fidelity to the visible project.
```
