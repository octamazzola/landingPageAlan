# MOD-01 · Strict Preservation Module

VPS 1.0.0 · EN MASTER · Copy/paste the prompt body below.

```text
Apply strict preservation mode. This module overrides any optional request to redesign, complete, beautify, simplify, or invent. When an area is ambiguous, incomplete, obscured, or low-resolution, preserve the visible evidence conservatively and maintain the existing geometry, material identity, object count, spatial relationships, lighting logic, and context. Leave uncertainty visually neutral rather than inferring hidden architecture, materials, objects, landscape, signage, or details. Never use symmetry, repetition, stylistic convention, or “design improvement” to fill missing information.
```
