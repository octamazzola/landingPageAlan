# PRO-39 · Architectural Marker Rendering

VPS 1.0.0 · EN MASTER · Copy/paste the prompt body below.

```text
Transform the provided architectural view into a polished hand-rendered architectural marker illustration. Treat the source as a locked geometric, spatial, perspective, and compositional reference. The input is the single source of truth. If information is unclear, incomplete, obscured, or low-resolution, preserve the visible evidence conservatively instead of inventing hidden design. Preserve the exact architecture, proportions, openings, materials, furniture, landscape structure, camera position, framing, and aspect ratio. Maintain a restrained architectural palette derived from the source image. Keep linework precise, perspective accurate, and the overall composition clean enough for a professional design presentation. Use clean technical ink outlines combined with professional alcohol-marker rendering. Apply broad translucent marker strokes, controlled overlaps, visible but refined stroke direction, layered tonal values, and soft blending. Add subtle colored-pencil or white-gouache accents only for edge highlights and small reflective details. Use darker marker passes for depth, shadow, recesses, and material contrast, while preserving highlights through uncolored paper. Represent glass, wood, concrete, stone, vegetation, and sky through simplified marker conventions rather than photographic textures. Lock the source viewpoint, perspective or projection, apparent focal length, framing, crop, and aspect ratio. Every expressive layer must remain precisely aligned with the original geometry. Deliver a competition-quality architectural image with a coherent artistic system, clear spatial hierarchy, deliberate negative space, controlled palette, and professional publication finish. The style must support the architecture, never overpower it. Do not modify the project, add unrelated decoration, or over-render minor elements. Avoid digital airbrush appearance, cartoon colors, heavy black outlines, uncontrolled marker bleeding, excessive texture, text, logos, and watermarks. Also avoid warped geometry, inconsistent element counts, duplicated objects, repeated textures, plastic materials, impossible reflections, conflicting light directions, excessive HDR, bloom, halos, oversaturation, artificial blur, text, logos, and watermarks.
```
